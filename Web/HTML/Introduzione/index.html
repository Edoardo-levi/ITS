Attributo: istruzione aggiuntiva del tag

il tag p, vine usato per inserire un testo descrittivo

il tag img serve per inserire le immagini

il tag a sta per ancora ed è un collegamento con un'altra pagina html

Esempio:

vai alla pagina di Amazon

il tag span è il fratello gemello di div e anche questo non fa niente con l'unica differenza che non va nemmeno a capo

il tag bgcolor serve per cambiare colore alla pagina

il tag ul con all'interno i tag li serve per creare liste non oridnate (le liste con i puntini)

  • Primo elemento
  • Secondo elemento
  • Terzo elemento

il tag ol con all'interno i tag li serve per creare liste ordinate (le liste con i numeri )

  1. primo elemento
  2. secondo elemento
  3. terzo elemento

il tag table con all'interno i tag tr e a loro interno i tag td, servono per creare tabelle

il tag th all'interno di una tabella serve per indicare una tabella che indica un intestazione. Ad esempio una riga contiene nomne e cognome, questi dati ce li mette in grassetto se usiamo il tag th

il tag form seve per creare appunto un form (una pagina di ivio dati)

E' composto così:

input: genera la maggior parte degli elementi del form a seconda del type specificato che bup essere:

  1. text: è utilizzato per creare caselle di testo in cui si può scrivere il contentuo
  2. file: è utilizzato per creare caselle di selezione di file in locale con lo scopo di poterli inviare. (per esempio la casella scegli file nei form che ti chiedono di inviare la foto del documetno)
  3. radio: è utilizzato per creare un gruppo di pozioni ache ammette SOLO UNA scela (esempio il gruppo di scelte per il sesso)
  4. checkbox: è utilizzato per creare gruppi di opzioni in cui possono essere selezionate più risposte (esempio gli interessei)
  5. button: è utilizzato per creare bottoni al quale può essere associata un operazione di javascript
  6. submit: è utilizzato per creare bottoni di invio dati. spesso usati a fine form per inviare dati
  7. reset: è utilizzato per resettare le risposte contentute nel form in modo da farlo ritornare al suo stato inizale

select: crea caselle di riepilogo a scrrrimento chiamate selectbox

textarea: serve per creare un area di testo in cui è possibile andare a capo e vinene utilizzata per permettere di inserire descrizioni, commenti o altro
